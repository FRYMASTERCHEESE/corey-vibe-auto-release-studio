Commercial-use setup

      
The website itself takes 0% of your royalties and claims no ownership share in tracks you create with it. Fast Local backing music is procedurally synthesized without downloaded beat samples. Fast Local neural vocals use Kokoro; optional Studio Singer sends the prompt and lyrics to the ACE-Step server you configure and downloads the generated full mix back into the release workflow.

      
No software can guarantee copyrightability, distributor acceptance or that a generated output never resembles existing material. Review the finished song, credits and platform rules before release.
