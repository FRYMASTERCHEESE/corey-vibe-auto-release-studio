# Output rights and commercial use — v8

Corey Vibe Auto Release Studio takes **0% of royalties or revenue** and claims no ownership share in songs, artwork, metadata, hook edits, cue sheets or other files generated by the website's own code.

To the extent the website project itself has rights to grant, the user may use, edit, reproduce, distribute, monetize, license, synchronize and commercially release project-generated material without paying the website or its author a royalty.

## Eleven Music imports

Audio generated by Eleven Music is governed by the user's ElevenLabs plan and the current Eleven Music terms. The website cannot grant rights to ElevenLabs-generated audio that it does not own.

The v8 workflow therefore treats **Eleven Music Free-plan imports as personal-use only** and does not mark them SoundOn/commercial-release ready. If the user has a plan or PAYG/API arrangement whose current terms permit the intended commercial release, the user can select the commercial workflow before importing. That selection is only a record of the user's status; it does not create or expand any licence.

## Fast Local / Studio Singer backups

The local backing-track engine creates audio procedurally in the browser. Fast Local neural vocals use third-party open-source components. Studio Singer uses the separately configured ACE-Step-compatible server. Third-party components remain under their own licences.
