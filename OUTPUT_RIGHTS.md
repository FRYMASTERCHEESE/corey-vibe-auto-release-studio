# Commercial output rights

Corey Vibe Auto Release Studio v2 is software for creating local procedural music, cover artwork, lyrics starters and release metadata.

## Project ownership and royalties

The project claims **no ownership share** in outputs a user creates with the software and takes **0% of royalties or revenue** from those outputs.

To the maximum extent the software author has rights that could restrict a user's use of an output created with this software, those rights are irrevocably waived. Where a waiver is not legally effective, the user receives a worldwide, perpetual, irrevocable, royalty-free, sublicensable licence to use, copy, edit, adapt, distribute, publicly perform, synchronize and commercially monetize that output.

## Important limits

This grant cannot give the user rights to third-party material they put into a prompt or otherwise add themselves, including someone else's protected lyrics, melodies, recordings, artwork, names, logos or trademarks.

This project generates music from oscillators, algorithmic note patterns, generated noise and effects. It does not ship with or download prerecorded music samples. Even so, no music tool can guarantee that a new melody will never coincidentally resemble an existing work.

Whether a particular output qualifies for statutory copyright protection depends on applicable law and the amount/nature of human authorship involved. Streaming services and distributors also apply their own current rules.
